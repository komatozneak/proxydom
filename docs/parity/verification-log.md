# Журнал проверки паритета

Каждая строка — не «должно работать», а измеренный факт: клиент поднял туннель
и трафик вышел из тестового стенда. Проверка идёт двумя независимыми путями на
одном и том же стенде.

**Стенд:** `31.59.170.81`, Ubuntu 24.04, Xray 26.3.27, по инбаунду на протокол,
самоподписанный сертификат `CN=31.59.170.81`. Конфиг стенда —
`.scratch/ref/lab/server-parity.json`, поднимается `provision.py` +
`deploy_server.py`.

## Как измеряется

- **ПК (Windows).** Реальный `proxydom-engine.exe` (тот же Go-исходник, что
  уезжает в APK) в режиме loopback-прокси, без TUN. Запрос
  `https://ifconfig.me/ip` через него; успех — ответ равен `31.59.170.81`,
  то есть пакет действительно вышел из стенда. Скрипт: `pc_verify.py`.
- **Телефон (Pixel 7 Pro, Android 17).** Debug-сборка `com.proxy.dom.debug`,
  ключ приходит deep link'ом (тот же путь, что «Открыть в Прокси Дом» из
  другого приложения), затем нажатие «Подключиться». Успех — строка приложения
  `vpn.egress_probe … ok=true result=ok external_ip=31.59.170.81
  phase=connectedHealthy`, которую оно пишет само. Скрипт: `device_loop3.ps1`.

## Что эта проверка нашла в клиенте

Стенд специально сделан с самоподписанным сертификатом: так видно, доезжает ли
до движка `allowInsecure` из ключа. Нашлись три настоящих дефекта, все
исправлены:

1. **VMess терял `allowInsecure`.** Он лежит внутри base64-JSON, а документ
   собирался только из query-строки, которой у VMess нет. Ключ, просивший не
   проверять сертификат, dial'ился с проверкой. Правка: `engine_share_config.dart`
   читает `allowInsecure` (bool/1/"1") и `verify_cert: false`; брокер Windows
   (`protocol.cpp`, `read_vmess_skip_verify`) — те же формы, включая `true`, а не
   только строку `"1"`.
2. **VMess-ссылка портилась по дороге.** `vmess://` держит base64 в authority, а
   `Uri` приводит host к нижнему регистру — payload менялся, ключ не разбирался,
   и узел молча не добавлялся. Правка: `MainActivity` запоминает
   `intent.dataString` и отдаёт его в Dart через `takeRawLink`; `app.dart`
   предпочитает сырую строку разобранному Uri.
3. **Голая ссылка из ОС не добавлялась.** `_openSubscription` только открывал
   экран импорта, а если приложение уже работало — не открывал и его. Правка:
   одиночный ключ сохраняется и приложение уходит на «Главную»; документ
   подписки по-прежнему открывает импорт.

Отдельно: алерт на телефоне больше не садится на нижнюю кнопку (уходит под
статус-бар и не перехватывает нажатия), а `_busy` экрана импорта сбрасывается в
`finally` — иначе кнопка «Сохранить» могла остаться неактивной навсегда.
