# Teremok VPN 0.1.13

Public tester notes (Internal / sideload). Not an engineering changelog.

## What is new

VPN no longer freezes after the screen locks. The tunnel stays up in the background; if it drops, the app restores it without toggling Connect off and on.

The notification shade again shows live download and upload speeds.

## How to update

This is a required update over 0.1.12. The old build will not heal itself.

1. Google Play, Internal testing: update Teremok VPN.
2. Or install the APK from the downloads site (same package as Play).

After update: connect, lock the screen for 5-10 minutes, unlock. Status should stay Connected and traffic should work.
