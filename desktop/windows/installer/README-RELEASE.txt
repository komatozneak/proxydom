ПРОКСИ ДОМ ДЛЯ WINDOWS
======================

Приложение бесплатное, работает локально и не отправляет ваши ключи на сервер.


ЧТО ИЗМЕНЕНО В ВЕРСИИ 1.5.28
---------------------------

Полоска трафика теперь показывает **остаток**: при `496 / 600` она заполнена
на 83%, а не на 17%. Подпись `использовано 104 / 600` осталась для сверки с
панелью. Так крупная цифра, надпись «осталось» и длина полоски говорят одно и
то же.

`Fallback-Url` больше не заменяет основной документ, если основной ответ уже
содержит рабочие строки. Раньше клиент уходил на резервный хост, не открывал
его и оставлял старый профиль. Теперь резервный адрес — только запасной, а
основной ответ сохраняется. `new-url` по-прежнему считается переездом.

Под именем профиля виден хост источника (`sub.example.com` или
«локальный импорт»), поэтому старый каталог нельзя спутать с проверяемой
ссылкой. Ручное обновление всегда делает полный GET без `If-None-Match`, а
повторный импорт того же URL переносит манифест, дату трафика и интервал
обновления вместе с новыми строками.

Профиль и узлы снова одна нейтральная пластина. У профиля крупное имя,
название тарифа и остаток трафика фоном; под ним полоска остатка с подписью
«использовано X / Y». Если сервер прислал срок действия, рядом стоит
«истекает: ДД.ММ.ГГГГ». Для 1 ТБ используется десятичная единица:
1 000 000 000 000 байт показываются как 1 ТБ, а не 931 ГБ.

Старые `subscription-userinfo` без манифеста показываются в бинарных
ГиБ, как их отдают панели: `total=107374182400` — это 100 ГБ на экране.
Манифест `proxydom-profile` использует десятичные ГБ/ТБ; так хостер может
показать ровно 100 ГБ и 1 ТБ.

Трафик теперь различает: нет данных, только расход, безлимит, потолок,
исчерпанный лимит и устаревшие данные. Полоска заполняется остатком, а подпись
показывает расход `X / Y`. Цвет меняется по остатку: меньше 20% — пламя,
ноль — опасный, а не абсолютные 5 ГиБ. Дата квоты не обновляется, если сервер
ответил 304 или не прислал subscription-userinfo.

Добавлен формат профиля `proxydom-profile` в заголовке подписки или строке
`#proxydom-profile:` в теле. Хостер может задать имя, описание, поддержку,
тариф и квоту; старые поля продолжают работать. Пособие для хостеров лежит
в `mobile/docs/subscription-profile.md` в исходниках.

ЧТО ИЗМЕНЕНО В ВЕРСИИ 1.5.22
---------------------------

В нижней панели Windows вместо «Скорости» теперь показывается «Пинг». Замер
идёт из самого приложения через активный туннель: запрос к `1.1.1.1:80`
раз в 5 секунд, число обновляется на месте. Если данных нет — `—`. Мобильные
платформы пока сохраняют «Скорость» и получат PING отдельным этапом.

На Windows у экрана «Добавить» убрана кнопка QR: у компьютера нет камеры,
которой можно сканировать код. Остаётся вставка из буфера и ввод вручную.
На Android и iOS QR-сканирование не менялось.

Статус в карточке сервера теперь маленькая «клавиша»: тонированная плашка с
подсветкой сверху, тонкой рамкой и мягкой тенью. Текст крупнее, точка 12 px.
Цвета состояний: зелёный — подключено, красный — подключение и ошибка, серый —
покой.

Статус прижат к правому краю карточки. Под домом осталось только одно
состояние — «Подключиться» в idle/error; «Отключить» и «Защищено · время»
убраны.

Во время подключения статус остался только в верхней карточке сервера. Под
домом больше нет второго «Подключение…» и «Подключаемся…». В карточке текст
статуса крупнее, а цветной индикатор стоит справа от него, у края.

Экран «Добавить» для Windows переработан под десктоп: две колонки — «Ссылка»
и «Найдено», без нумерации шагов и без пустой середины. Слева поле ввода и
способы вставки, справа — превью серверов из документа с количеством. Панели
одной высоты, внизу слева — строка о том, что ключи не уходят на сервер.

Кнопки собраны в нижнюю панель: «Назад» слева, «Сохранить» справа. «Назад»
больше не попадает в зону перетаскивания окна.

Шапка окна теперь общая для всех экранов: свернуть, развернуть, закрыть и
перетаскивание доступны и в онбординге, и на «Добавить», а не только на
главной.

Ошибка 1909 при восстановлении установки. Ярлык на рабочем столе больше не
копирует `proxy_dom.exe` в кэш установщика как источник иконки: иконка берётся
из самого exe, как у ярлыка в меню «Пуск». Копирование падало с ошибкой 2318 и
превращалось в предупреждение «Не удалось создать ярлык».

Заодно убрана асинхронная остановка службы перед установкой. Она могла сработать
уже после запуска службы и оставить её остановленной после восстановления.
Теперь остановкой занимается стандартный `StopServices`, а после обновления
служба запускается явно.

Онбординг на Windows теперь один экран вместо мобильных карточек: короткое
объяснение, что вставить ключ или ссылку на документ, строка о хранении ключей
на компьютере и две кнопки — «Добавить сервер» и «Позже». Экрана про разрешение
Android на ПК больше нет.

Из текстов убраны «домик», «дом открывает дверь» и прочие метафоры. Пока идёт
подключение, приложение пишет «Подключаемся…»; на главном экране —
«Нажмите, чтобы подключиться» и «Подключено».

«Белые списки» на компьютере теперь определяют сайт по имени в защищённом
соединении (TLS SNI или HTTP Host), а не только по ответу DNS. Поэтому список
работает и при включённом в браузере защищённом DNS (DoH), и на адресах,
которые делят несколько сайтов. На VLESS список тоже применяется.

UDP (звонки, игры, QUIC) по умолчанию идёт через туннель, а не мимо него.
Если игра стала тормозить — это ожидаемо: отдельный режим «прямой UDP для игр»
появится в следующем обновлении.

Установщик больше не запускает приложение сам и не выполняет в фоне
«reconcile» — эти действия могли оставить транзакцию Windows Installer
висеть. Остановка службы ограничена 15 секундами, а подробный журнал
установки пишется в %TEMP%\MSI*.log.

Отдельно исправлена причина зависания на этой машине: Windows Installer
выбирал для установки диск `Z:`, который сейчас недоступен, и зависал на
проверке свободного места. Теперь корневой диск жёстко закреплён за `C:`.


ЕСЛИ УСТАНОВКА ЗАВИСЛА
----------------------

1. Не запускайте установщик второй раз, пока открыт первый: Windows ответит
   «Производится другая установка».
2. Если окно не реагирует, нажмите «Отмена». Если и это не помогло, запустите
   `reset-msi.ps1` **от имени администратора** — он перезапускает службу
   Windows Installer и снимает зависшую транзакцию без перезагрузки.
3. Если перезапуск службы не помог — перезагрузите компьютер.
4. После этого запустите MSI один раз. Если снова зависнет, пришлите свежий
   файл %TEMP%\MSI*.log — по нему видно, на каком действии это вышло.


ЕСЛИ WINDOWS ПИШЕТ, ЧТО ПРИЛОЖЕНИЕ ЗАБЛОКИРОВАНО
------------------------------------------------

На Windows 11 есть функция «Интеллектуальное управление приложениями»
(Smart App Control). Она не пускает программы, которые не подписаны
сертификатом проверенного издателя, и показывает диалог:

  «Интеллектуальное управление приложениями заблокировало приложение,
   которое может быть небезопасным...
   не удалось проверить издателя, чтобы убедиться в безопасности запуска».

Это не вирус и не ошибка установщика. Сборка пока выпускается без цифровой
подписи, поэтому Windows не может проверить издателя. Варианта два:

1. Выключить Smart App Control:
   Параметры → Конфиденциальность и защита → Безопасность Windows →
   Управление приложениями и браузером → Smart App Control → Выкл.

   Важно: обратно включить её можно только переустановкой Windows.
   Это настройка безопасности для всех программ на компьютере, а не для
   одного приложения, — выключайте, только если понимаете это.

2. Дождаться подписанной сборки. Подпись уже встроена в сборку, ждём
   сертификат. Такие сборки Windows запускает без этого диалога.


ЕСЛИ SMARTSCREEN ПИШЕТ «WINDOWS ЗАЩИТИЛА ВАШ КОМПЬЮТЕР»
-------------------------------------------------------

Это предупреждение о репутации нового файла, а не о вирусе:
  «Подробнее» → «Выполнить в любом случае».

Если кнопки «Выполнить в любом случае» нет: правой кнопкой по файлу →
Свойства → внизу «Разблокировать» → ОК.


ЕСЛИ АНТИВИРУС РУГАЕТСЯ
-----------------------

Не отключайте антивирус целиком и не добавляйте папку в исключения.
Пришлите файл в Microsoft: https://www.microsoft.com/wdsi/filesubmission
и напишите нам — разберёмся.


ЧЕГО ДЕЛАТЬ НЕ НУЖНО
--------------------

- скачивать сборки с зеркал и «активаторов»;
- отключать Microsoft Defender;
- добавлять в исключения целую папку или диск.
