# Прокси Дом — расширение для браузера

Нажмите на домик в панели Chrome/Edge — текущая страница добавится в «Белые списки» Прокси Дом вместе с найденными плеерами. После этого переподключите VPN в приложении, чтобы маршрут применился.

## Установка (Chrome / Edge)

1. Откройте `chrome://extensions` (или `edge://extensions`).
2. Включите «Режим разработчика».
3. Нажмите «Загрузить распакованное» и выберите папку `browser-extension`.
4. Закрепите домик на панели.

Приложение Прокси Дом должно быть запущено: расширение общается с ним через локальный порт `127.0.0.1` (47821–47823). Наружу ничего не отправляется.

## Как это работает

- Домик читает адрес активной вкладки и отправляет его в приложение.
- Приложение сохраняет только домен, без пути и параметров.
- Если страница доступна для чтения, приложение сразу ищет в ней `iframe`/player/video-хосты и сохраняет их как плееры сайта.
- Если страница закрыта антиботом и плееры появляются только после JavaScript, автоматически их не видно. Тогда добавьте домен плеера в «Белые списки» отдельным сайтом.

## Ограничения

- Только Chromium-браузеры (Chrome, Edge, Яндекс Браузер, Opera и т. п.).
- Нужна версия приложения 1.5.36 или новее.
- Расширение не публикуется в Chrome Web Store: устанавливается распакованной папкой.
